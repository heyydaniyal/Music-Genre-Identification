# Decoding the Rhythms of Emotion — Text Mining 2026/27 (NOVA IMS)

Genre classification (Kaggle, macro F1) and sentiment analysis of song lyrics.
**The notebooks are the report**: run them in order 01 → 05.

## Structure

```
Music-Genre-Identification/
├── data/
│   ├── raw/            ← put train.csv, test.csv, sample_submission.csv here (git-ignored)
│   └── processed/      ← files passed between notebooks (git-ignored, written by 02)
├── notebooks/
│   ├── _setup.py                     shared setup, run by every notebook with %run ./_setup.py
│   ├── 01_eda.ipynb                  Abstract, Introduction, Data exploration
│   ├── 02_preprocessing.ipynb        Cleaning; writes train_clean.pkl / test_clean.pkl
│   ├── 03_genre_classification.ipynb Models, evaluation, Kaggle submission
│   ├── 04_sentiment_analysis.ipynb   Sentiment method checks and research questions
│   └── 05_conclusion_annexes.ipynb   Conclusion, References, Annexes
├── src/
│   ├── config.py           paths, columns, labels, seed: the single source of truth
│   ├── data.py             load the processed files passed between notebooks
│   ├── features.py         low-memory side-by-side stacking of sparse matrices (notebook 03)
│   ├── sentiment.py        line-level VADER, TextBlob, profanity list
│   ├── stats.py            Kruskal-Wallis, Cliff's delta, Holm, bootstrap CIs
│   ├── submission.py       Kaggle file writing (validated), hashing, logging

├── docs/               decision_log.md
└── scripts/run_all.py  executes 01→05 in order (QA)
```

## Setup

Python **3.11** (3.12 also works).

```bash
# conda
conda env create -f environment.yml && conda activate text-mining-lyrics
# or venv
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt        # add -r requirements-dev.txt for pytest

nbstripout --install      # strips notebook outputs from git commits only (not from your files)
```

Download the competition data and place the three CSVs in `data/raw/`.

## Hardware and runtime

A full run takes about 35 minutes on a laptop CPU (notebook 03 about 15–20 min, notebook 04 about 12 min).
Notebook 03's final refit on all songs needs about **6 GB of RAM** at its peak: use a machine with at least 8 GB
(16 GB is comfortable).

## Run

Open the notebooks in order 01 → 05, or run them all:

```bash
python scripts/run_all.py --fresh
```

## Code rules (DRY)

1. **No duplicated logic.** If code would appear in two notebooks, it goes in `src/`.
2. **No hard-coded paths, columns, labels or seeds** outside `src/config.py`.
3. **One config dict drives cleaning and representations**, so ablations change settings, not code.
4. **Notebooks orchestrate and narrate.** Every cell has one purpose and a markdown "why" above it.
5. **Handoffs are verified.** Processed files carry a config hash that downstream notebooks check.
6. **Allowed stack only:** scikit-learn (vanilla), NLTK, Gensim, pandas, NumPy, SciPy, Matplotlib, Seaborn.
   Never: XGBoost, LightGBM, CatBoost, imbalanced-learn, AutoML, pretrained models or embeddings.

## Kaggle

`results/submission_log.csv`. Exactly one final submission, regenerated byte-for-byte by notebook 03.
